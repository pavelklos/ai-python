## Modern Machine Learning Workflow
- Define the problem and objectives
- Collect and import data
- Explore and clean the data
- Perform feature engineering
- Split data into training/validation/test sets (typically 70/15/15 or 80/10/10)
- Select appropriate models
- Train models and tune hyperparameters
- Evaluate model performance
- Interpret results and draw insights
- Deploy the model to production
- Monitor and maintain the model
- Iterate and improve

*The most challenging aspects are often data collection, cleaning, and feature engineering*<br>
*High-quality, diverse datasets are crucial for model performance*

## End-to-End Machine Learning Pipeline
- Data acquisition (APIs, databases, web scraping)
- Data preparation (handling missing values, outliers, transformations)
- Feature engineering (creating new features, dimensionality reduction)
- Model selection (comparing algorithms suited to the problem)
- Model training (fitting models to training data)
- Hyperparameter optimization (grid search, random search, Bayesian optimization)
- Cross-validation (k-fold CV, stratified CV)
- Model evaluation (metrics: accuracy, precision, recall, F1, AUC-ROC, RMSE)
- Model interpretation (feature importance, SHAP values, partial dependence plots)
- Model deployment (REST APIs, containerization, serverless)
- Monitoring (drift detection, performance metrics)
- Retraining strategy (scheduled or trigger-based)

## Tools In Machine Learning

- [Kaggle](https://www.kaggle.com/)
  - is community of data scientists and machine learning practitioners
  - is platform for predictive modeling and analytics competitions
  - access to datasets, notebooks, kernels, discussions, etc.

- [NumPy](https://numpy.org/)
  - is library for numerical computing
  - provides support for large, multi-dimensional arrays and matrices
  - working with lists, arrays, matrices, etc.

- [pandas](https://pandas.pydata.org/)
  - is library for data manipulation and analysis
  - provides data structures like Series and DataFrame
  - working with tabular data (rows, columns) CSV, Excel, SQL, etc.

- [Scikit-learn](https://scikit-learn.org/)
  - is library for machine learning
  - provides support for classification, regression, clustering, etc.
  - working with algorithms like SVM, KNN, Random Forest, etc.
  - working with metrics like accuracy, confusion matrix, classification report, etc.

- [Matplotlib](https://matplotlib.org/)
  - is charting library for creating static, animated, and interactive visualizations in Python
  - provides support for line plots, bar plots, histograms, pie charts, scatter plots, etc.

- [Anaconda](https://www.anaconda.com/)
  - is distribution of Python and R programming languages for scientific computing
  - provides support for data science, machine learning, deep learning, etc.
  - provides support for Jupyter Notebook, Spyder, etc.
  - provides support for libraries like NumPy, pandas, scikit-learn, Matplotlib, etc.

- [Jupyter Notebook](https://jupyter.org/) ([Docs](https://docs.jupyter.org/en/latest/))
  - is open-source web application for creating and sharing documents that contain live code, equations, visualizations, and narrative text
  - provides support for code, markdown, LaTeX, etc.

- [Plotly](https://plotly.com/)
  - Library for creating interactive, web-based visualizations
  - Supports over 40 chart types including 3D plots, statistical charts, and maps
  - Enables creation of dashboards and supports animation and real-time updates

- [TensorFlow](https://www.tensorflow.org/)
  - End-to-end machine learning platform with comprehensive ecosystem
  - Provides flexible architecture for deployment across devices
  - Features TensorFlow Extended (TFX) for production ML pipelines and TensorFlow.js for browser-based ML

- [PyTorch](https://pytorch.org/)
  - Dynamic deep learning framework with pythonic design
  - Offers imperative programming style with automatic differentiation
  - Includes TorchScript for seamless transition between eager and graph modes
